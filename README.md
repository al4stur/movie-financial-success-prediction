# movie-financial-success-prediction
Predicting movie hits vs. flops and revenue using budget, runtime, and genre ||  KNN, Logistic Regression, and Linear Regression in Python (TMDB 5000 dataset)

Using the TMDB 5000 dataset, I built KNN and Logistic Regression models to classify movies as hits or flops, and a Linear Regression model to predict revenue directly (R² = 0.577). A key finding: the more "accurate" model completely failed at the actual task, while a lower-accuracy model caught real flops

References:
TMDB 5000 Movie Dataset. (2017). The Movie Database (TMDB), via Kaggle. https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
